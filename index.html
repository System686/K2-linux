1. Introduzione

Benvenuto nell'Handbook ufficiale di K2 Linux. Questa guida descrive la procedura dettagliata per l'installazione, la configurazione e la gestione del sistema operativo partendo dall'archivio base Stage3.

2. Requisiti di Sistema

Prima di procedere con l'installazione, assicurati di disporre dell'hardware minimo richiesto:

  • Architettura: x86_64 (64-bit)
  • Memoria RAM: Almeno 512 MB (consigliato 1 GB)
  • Spazio di archiviazione: Minimo 3 GB liberi

3. Gestione ed Estrazione dello Stage3

L'archivio dello Stage3 (solitamente denominato k2-rootfs) deve essere estratto correttamente preservando i permessi dei file.

Nota: Assicurati di estrarre l'archivio all'interno della cartella di lavoro designata (es. ~/k2-rootfs) per evitare errori di percorso nei passi successivi. 
# Spostati nella home ed estrai l'archivio
cd ~
tar xpvf k2-rootfs.tar.xz

4. Configurazione del Chroot

Per accedere all'ambiente isolato e operare sul sistema K2, è necessario montare i file system virtuali e configurare i binari e le librerie (inclusi bash e le dipendenze della glibc):

# Montaggio dei file system virtuali
sudo mount -t proc none ~/k2-rootfs/proc
sudo mount --rbind /sys ~/k2-rootfs/sys
sudo mount --rbind /dev ~/k2-rootfs/dev

# Ingresso nel sistema tramite chroot
sudo chroot ~/k2-rootfs /bin/bash

5. Ricompattare il Rootfs

Una volta completate le configurazioni e l'installazione dei pacchetti all'interno del chroot, puoi generare nuovamente l'archivio compresso del sistema:

cd ~
tar cpJf k2-rootfs-updated.tar.xz k2-rootfs
