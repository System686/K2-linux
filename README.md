# K2-linux
K2 linux a diy distro

K2 linux is a diy minimal distro that is purpose is to be fast, secure, reliable and made for every day users.

To download K2-Linux go to https://system686.github.io/K2-linux/ where you will find the K2-linux stage3, handbook and soon a dedicated live iso
