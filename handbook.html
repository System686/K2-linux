K2-Linux Handbook

Official guide for minimal system installation and the peak / climb ecosystem.

1. Disk Preparation

Boot from a Live ISO environment and partition your target drive (e.g., /dev/sda or /dev/nvme0n1).

Creating Partitions (UEFI/GPT)

# Partition the disk using cfdisk
cfdisk /dev/sda

# Example layout:
# /dev/sda1 -> 512M (EFI System Partition)
# /dev/sda2 -> Remaining space (Linux Root)

# Format the partitions
mkfs.vfat -F32 /dev/sda1
mkfs.ext4 /dev/sda2

Mounting Filesystems

# Mount the root partition
mount /dev/sda2 /mnt

# Create and mount the EFI directory
mkdir -p /mnt/boot/efi
mount /dev/sda1 /mnt/boot/efi

2. Base System Bootstrap

Extract the minimal K2-Linux RootFS and bind the virtual kernel filesystems before entering the chroot environment.

# Extract the base system
tar -xvf k2-base-rootfs.tar.xz -C /mnt

# Mount virtual filesystems
mount --bind /dev /mnt/dev
mount --bind /dev/pts /mnt/dev/pts
mount --bind /proc /mnt/proc
mount --bind /sys /mnt/sys
mount --bind /run /mnt/run

# Enter the K2-Linux chroot environment
chroot /mnt /bin/bash

3. Environment & Variables Setup

Configure the system environment script at /etc/profile.d/k2-env.sh so the shell locates system binaries, KUR paths, and default CLI tools.

cat << 'EOF' > /etc/profile.d/k2-env.sh
#!/usr/bin/env bash

export PATH="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:${PATH}"
export MANPATH="/usr/share/man:${MANPATH:-}"

export KUR_REPO_URL="https://github.com/k2-linux/kur.git"
export KUR_BRANCH="k2-user-repository"

export K2_CACHE_DIR="${HOME}/.cache/k2"
export K2_BUILD_DIR="${HOME}/.cache/k2/build"

export EDITOR="micro"
export VISUAL="micro"
export PAGER="less"
export BROWSER="links"
export TERM="xterm-256color"
EOF

source /etc/profile.d/k2-env.sh

4. Kernel, GRUB & Tool Installation

Download, build, and install core packages from the K2 User Repository using the climb package manager helper.

# Install the K2-optimized Linux Kernel
climb -S linux-k2

# Install the GRUB bootloader
climb -S grub-k2

# Install default text editor and TUI browser
climb -S micro
climb -S links
Note: climb fetches the PEAKBUILD recipes from the k2-user-repository branch, builds them using peak-build, and delegates installation to peak.

5. Bootloader Setup & Finalize

Install GRUB onto your drive and generate the configuration file for loading vmlinuz-k2 at startup.

# Install GRUB for UEFI systems
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=K2-Linux

# Generate boot configuration file
grub-mkconfig -o /boot/grub/grub.cfg

# Set the root password
passwd

Exit & Reboot

# Exit the chroot environment
exit

# Unmount all partitions
umount -R /mnt

# Reboot into K2-Linux
reboot
