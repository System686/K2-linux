1. Introduzione

Benvenuto nell'Handbook ufficiale di K2 Linux. Questa guida ti accompagnerà passo dopo passo nell'installazione manuale della distribuzione tramite l'archivio Stage3 e la configurazione del sistema di init OpenRC.

2. Requisiti di Sistema

K2 Linux è progettato per essere estremamente leggero:

  • CPU: 64-bit (x86_64)
  • RAM: Minimo 512 MB (consigliato 1 GB)
  • Spazio su disco: Almeno 3 GB liberi

3. Installazione dello Stage3

Per installare il sistema di base partendo dal tarball dello Stage3, avvia una live environment (anche da un'altra distro) e segui questi comandi:

# Partiziona e formatta il disco (es. /dev/sda1)
mkfs.ext4 /dev/sda1

# Monta il filesystem
mount /dev/sda1 /mnt/k2
cd /mnt/k2

# Scarica ed estrai lo Stage3
tar xpf /path/to/k2-rootfs.tar.gz

4. Chroot e Configurazione

Entra nel nuovo ambiente di K2 Linux tramite chroot per configurare i componenti essenziali:

mount -t proc none /mnt/k2/proc
mount --rbind /sys /mnt/k2/sys
mount --rbind /dev /mnt/k2/dev

chroot /mnt/k2 /bin/bash

Una volta dentro il chroot, potrai impostare la password di root, configurare la rete e gestire i pacchetti tramite XBPS.
