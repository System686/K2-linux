K2-Linux Handbook

Guida ufficiale all'installazione minimale del sistema e dell'ecosistema peak / climb.

1. Preparazione del Disco

Avvia il sistema da una Live ISO ed effettua il partizionamento del disco di destinazione (es. /dev/sda o /dev/nvme0n1).

Creazione delle partizioni (UEFI/GPT)

# Partiziona il disco con cfdisk
cfdisk /dev/sda

# Esempio di schema:
# /dev/sda1 -> 512M (EFI System Partition)
# /dev/sda2 -> Resto del disco (Linux Root)

# Formattazione delle partizioni
mkfs.vfat -F32 /dev/sda1
mkfs.ext4 /dev/sda2

Montaggio dei Filesystem

# Monta la root di destinazione
mount /dev/sda2 /mnt

# Crea e monta la partizione EFI
mkdir -p /mnt/boot/efi
mount /dev/sda1 /mnt/boot/efi

2. Bootstrap del Sistema Base

Estrai la RootFS di base di K2-Linux ed esegui il bind dei filesystem virtuali prima di entrare in ambiente chroot.

# Estrazione del sistema base
tar -xvf k2-base-rootfs.tar.xz -C /mnt

# Montaggio dei filesystem virtuali
mount --bind /dev /mnt/dev
mount --bind /dev/pts /mnt/dev/pts
mount --bind /proc /mnt/proc
mount --bind /sys /mnt/sys
mount --bind /run /mnt/run

# Entra nell'ambiente K2-Linux
chroot /mnt /bin/bash

3. Configurazione dell'Ambiente e Variabili

Configura lo script delle variabili di sistema in /etc/profile.d/k2-env.sh per far individuare i binari, i percorsi KUR e l'editor di testo predefinito.

cat << 'EOF' > /etc/profile.d/k2-env.sh
#!/usr/bin/env bash

export PATH="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:${PATH}"
export MANPATH="/usr/share/man:${MANPATH:-}"

export KUR_REPO_URL="https://github.com/k2-linux/kur.git"
export KUR_BRANCH="k2-user-repository"

export K2_CACHE_DIR="${HOME}/.cache/k2"
export K2_BUILD_DIR="${HOME}/.cache/k2/build"

export EDITOR="micro"
export VISUAL="micro"
export PAGER="less"
export BROWSER="links"
export TERM="xterm-256color"
EOF

source /etc/profile.d/k2-env.sh

4. Installazione di Kernel, GRUB e Strumenti

Scarica ed installa i pacchetti fondamentali dal K2 User Repository usando il gestore pacchetti climb.

# Installa il Kernel ottimizzato per K2
climb -S linux-k2

# Installa il Bootloader GRUB
climb -S grub-k2

# Installa l'editor di testo e il browser TUI
climb -S micro
climb -S links
Nota: climb scaricherà le ricette PEAKBUILD dal ramo k2-user-repository, le compillerà tramite peak-build e passerà l'installazione a peak.

5. Configurazione del Bootloader e Chiusura

Installa GRUB sul disco ed installa il file di configurazione per il caricamento del kernel vmlinuz-k2.

# Installazione di GRUB per sistemi UEFI
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=K2-Linux

# Generazione del file di configurazione automatico
grub-mkconfig -o /boot/grub/grub.cfg

# Configurazione della password di root
passwd

Uscita e Riavvio

# Esce dal chroot
exit

# Smonta tutte le partizioni
umount -R /mnt

# Riavvia il sistema
reboot
