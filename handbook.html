🏔️ K2 OS Handbook

Guida Passo-Passo all'Installazione e Compilazione del Sistema Operativo

📋 Requisiti Prerequisiti

  • Un PC con Linux attivo (il tuo sistema host).
  • Privilegi di amministrazione (sudo).
  • Connessione a Internet attiva per lo scaricamento dei binari statici e dei pacchetti.
  • Strumenti essenziali installati sull'host: wget, tar, xz, squashfs-tools, e genisoimage (o xorriso).

🛠️ Step 1: Preparazione dell'Ambiente e di K2 RootFS

Iniziamo creando la struttura del filesystem temporaneo di K2 e scaricando i binari statici del package manager XBPS.

# 1. Creazione delle directory di lavoro
sudo mkdir -p /mnt/k2-rootfs
cd /tmp

# 2. Download dei binari statici di XBPS (versione musl)
wget https://repo-default.voidlinux.org/static/xbps-static-latest.x86_64-musl.tar.xz

# 3. Estrazione dei binari
mkdir -p xbps-static
tar -xf xbps-static-latest.x86_64-musl.tar.xz -C xbps-static

# 4. Copia dell'albero di directory e dei binari nel RootFS di K2
sudo mkdir -p /mnt/k2-rootfs/usr/bin /mnt/k2-rootfs/var/db/xbps/keys /mnt/k2-rootfs/etc/xbps.d
sudo cp -a xbps-static/usr/bin/* /mnt/k2-rootfs/usr/bin/
sudo cp -a xbps-static/var/db/xbps/keys/* /mnt/k2-rootfs/var/db/xbps/keys/

# 5. Creazione del symlink standard da /bin a /usr/bin
sudo ln -s /usr/bin /mnt/k2-rootfs/bin 2>/dev/null || true

⚙️ Step 2: Configurazione dei Repository e della Rete

Configuriamo i mirror veloci e i server DNS affinché XBPS possa operare correttamente in chroot.

# 1. Configurazione del mirror di rete principale (EU Mirror)
echo "repository=https://alpha.de.repo.voidlinux.org/current/musl" | sudo tee /mnt/k2-rootfs/etc/xbps.d/00-repository-main.conf

# 2. Definizione esplicita dell'architettura target
echo "architecture=x86_64-musl" | sudo tee /mnt/k2-rootfs/etc/xbps.d/arch.conf

# 3. Configurazione dei server DNS per la risoluzione dei nomi
sudo mkdir -p /mnt/k2-rootfs/etc
echo "nameserver 1.1.1.1" | sudo tee /mnt/k2-rootfs/etc/resolv.conf
echo "nameserver 8.8.8.8" | sudo tee -a /mnt/k2-rootfs/etc/resolv.conf

🌀 Step 3: Entrare in Chroot e Popolare K2 OS

Montiamo i filesystem virtuali ed entriamo nell'ambiente isolato per installare i programmi base.

# 1. Montaggio dei filesystem di sistema dell'host
sudo mount --bind /dev /mnt/k2-rootfs/dev
sudo mount --bind /proc /mnt/k2-rootfs/proc
sudo mount --bind /sys /mnt/k2-rootfs/sys

# 2. Accesso all'ambiente chroot
sudo chroot /mnt/k2-rootfs /bin/sh
I comandi seguenti vanno eseguiti dentro la shell del chroot:
# 3. Impostazione delle variabili d'ambiente essenziali
export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
export XBPS_ARCH=x86_64-musl

# 4. Sincronizzazione ed installazione dei pacchetti base
xbps-install -Sy
xbps-install -y base-files ca-certificates busybox nano htop curl git

# 5. Uscita dal chroot
exit
# 6. Smontaggio pulito dei filesystem
sudo umount -R /mnt/k2-rootfs/dev
sudo umount -R /mnt/k2-rootfs/proc
sudo umount -R /mnt/k2-rootfs/sys

📦 Step 4: Creazione del Core Archive (k2-core.tar.gz)

Racchiudiamo il sistema operativo in un unico archivio compresso, ignorando le directory di runtime del kernel.

cd /mnt
sudo tar --exclude='k2-rootfs/proc/*' \
         --exclude='k2-rootfs/sys/*' \
         --exclude='k2-rootfs/dev/*' \
         --exclude='k2-rootfs/run/*' \
         --exclude='k2-rootfs/tmp/*' \
         -cvpzf k2-core.tar.gz k2-rootfs

💿 Step 5: Assemblaggio della Live ISO Offline

Integriamo l'archivio k2-core.tar.gz e uno script di installazione dentro il filesystem della Live ISO Buildroot.

1. Creazione dell'Overlay di Buildroot

mkdir -p ~/buildroot/board/k2/overlay/root/
cp /mnt/k2-core.tar.gz ~/buildroot/board/k2/overlay/root/

2. Creazione dello Script di Installazione (k2-install)

Crea il file ~/buildroot/board/k2/overlay/usr/bin/k2-install ed inserisci:

#!/bin/sh
echo "=== Installatore Automatico K2 OS ==="
if [ -z "$1" ]; then
    echo "Uso: k2-install /dev/sdX"
    exit 1
fi

DISK=$1
echo "Formattazione di ${DISK}1 in corso..."
mkfs.ext4 -F ${DISK}1

echo "Montaggio della partizione target..."
mkdir -p /mnt/target
mount ${DISK}1 /mnt/target

echo "Scompattamento del sistema K2 OS..."
tar -xzf /root/k2-core.tar.gz -C /mnt/target

echo "Installazione completata con successo! Ora puoi riavviare."
# Rendi lo script eseguibile
chmod +x ~/buildroot/board/k2/overlay/usr/bin/k2-install

3. Compilazione dell'ISO

cd ~/buildroot
make menuconfig
# Configura: System configuration -> Root filesystem overlay directories
# Imposta il percorso su: board/k2/overlay

make

🚀 Step 6: Scrittura su USB e Avvio di K2 OS

  1. Scrivi l'immagine sulla tua chiavetta USB (sostituisci /dev/sdX con il tuo dispositivo): 
    sudo dd if=output/images/rootfs.iso9660 of=/dev/sdX bs=4M status=progress conv=fdatasync
  2. Inserisci la chiavetta USB nel PC target ed esegui l'avvio da BIOS/UEFI.
  3. Avvia l'installazione guidata digitando: 
    k2-install /dev/sda
