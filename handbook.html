1. Introduction

Welcome to the official K2 Linux Handbook. K2 is a minimalist, independent Linux distribution built around BusyBox, OpenRC, and the XBPS package manager. This guide covers installation, service configuration, and package management.

2. Installing from Stage3

If you downloaded the Stage3 tarball, you can extract it onto any formatted ext4 partition to set up your root file system manually.

Extracting the Archive

mkdir /mnt/k2
mount /dev/sdX1 /mnt/k2
cd /mnt/k2
tar -xzvf /path/to/k2-rootfs-stage3.tar.gz

3. Managing Services with OpenRC

K2 Linux uses OpenRC as its init system. Services are located in /etc/init.d and can be managed using standard commands inside the system.

Enable a service on boot

rc-update add [service_name] default

Start/Stop a service manually

rc-service [service_name] start

4. Package Management with XBPS

Software installation and updates are handled through XBPS. Make sure your repository configuration points to the official mirrors.

Sync repositories and install a package

xbps-install -S
xbps-install [package_name]

Search for a package

xbps-query -Rs [search_term]
